# LeiloesTDSat

## Sobre o projeto

O LeiloesTDSat é um sistema desenvolvido em Java para auxiliar nas atividades de uma casa de leilões.

O projeto permite realizar o cadastro e a listagem de produtos, facilitando a organização e o gerenciamento das informações.

## Tecnologias utilizadas

- Java
- MySQL
- JDBC
- Apache NetBeans IDE
